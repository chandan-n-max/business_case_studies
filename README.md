# Business Case Studies

A collection of Data Science and Machine Learning case studies on real-world business problems — spanning exploratory data analysis, statistical testing, SQL analytics, and end-to-end machine learning modelling.

Built as part of MS in Computer Science (AI/ML) at Woolf University / Scaler Neovarsity.

---

## Case Studies

| # | Case Study | Domain | Type | Techniques |
|---|------------|--------|------|------------|
| 1 | Aerofit Treadmill | Fitness / Retail | EDA & Statistics | Descriptive stats, probability, customer profiling |
| 2 | Walmart | Retail | EDA & Statistics | Confidence intervals, CLT, hypothesis testing |
| 3 | Yulu | Mobility | EDA & Hypothesis Testing | t-test, chi-square, ANOVA |
| 4 | Delhivery | Logistics | EDA & Feature Engineering | Data cleaning, aggregation, distribution analysis |
| 5 | Netflix | Entertainment | EDA | Content analysis, trend analysis, visualisation |
| 6 | Ad Ease | AdTech | EDA | Segmentation, performance analysis |
| 7 | Target (SQL) | E-commerce | SQL Analytics | BigQuery, joins, time-series, customer segmentation |
| 8 | Jamboree Education | EdTech | Machine Learning | Linear Regression |
| 9 | LoanTap | Fintech | Machine Learning | Logistic Regression |
| 10 | OLA | Mobility | Machine Learning | Ensemble Learning (Random Forest, XGBoost) |
| 11 | Scaler | EdTech | Machine Learning | Clustering (K-Means, Hierarchical) |
| 12 | Zee | Entertainment | Machine Learning | Recommender Systems |
